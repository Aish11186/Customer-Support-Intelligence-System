# Customer Support Intelligence System <br>
This is a plug-and-play ML middleware that predicts optimal human handoff points in chatbot conversations, reducing silent
churn in automated support systems for e-marketplaces and D2C startups.<br>
It's trained on 400+ chatbot interaction logs and includes NLP features like sentiment trajectory, repetition and fallback detection. 
Deployed a regression model via a Flask API.<br>
This system achieves 2–3s faster decision-making than LLM-based solutions, enabling cost reduction and real-time insights.<br>
