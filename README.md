# Customer Support Intelligence System <br>
This is a plug-and-play ML middleware that:<br>
->predicts optimal human handoff points in chatbot conversations<br>
-> Maintains context through chained conversations between several support executives<br>
-> and doubles as a market research agent<br>
Helps reduce the 'silent churn' due to poor automated support systems and customer support pipelines.<br>
Specifically caters to e-marketplaces, e-commerce and quick commerce brands and D2C startups.<br>
It's trained on 1400+ chatbot interaction logs and includes NLP features like sentiment trajectory, repetition and fallback detection. <br>
Deployed a regression model and an end-to-end pipeline via a Flask API.<br>
This system achieves 2–3s faster decision-making than LLM-based solutions per response (as it utilises an in-house model), enabling cost reduction and automated real-time insights (like product and system faults, common fragmentation points, etc.).<br>
